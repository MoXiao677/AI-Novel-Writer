# 虚构小说示例

`novel.json` 使用虚构小说《雾港来信》演示六类数据：小说项目、全书大纲、章节细纲、人物、正文、版本记录。

示例包含 2 位人物、1 章正文与 2 个历史版本。第 1 版保留简短草稿，第 2 版保留确认后的内容，两版内容同时存在。固定日期只是示例数据，不代表程序已经执行保存或作者审核。

示例 ID 使用容易阅读的 `demo-` 名称。实际程序默认生成 UUID 字符串；两者都使用稳定字符串建立关联。

从仓库根目录运行：

```powershell
python scripts/validate_example.py
```

实际小说后续约定放在被 Git 忽略的 `data/` 下，不要把私人正文放入示例目录。
