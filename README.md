# AI-Novel-Writer

一个面向长篇小说创作的 AI 多模型协作平台。

## 项目简介

AI-Novel-Writer 旨在帮助作者减少小说创作过程中的重复劳动，通过自动化工作流，将大纲、章节细纲、章节构思、正文生成、内容审核和最终改写整合到一个统一的平台中。

作者只需要提供全书大纲，并为每一章输入核心想法，系统即可按照预设的创作流程协作完成后续工作。

## 核心目标

- 自动化长篇小说创作流程
- 支持多个 AI 模型协同工作
- 自动生成章节细纲与章节构思
- 自动生成章节正文
- 检查剧情逻辑与时间线
- 检查人物设定与剧情连续性
- 审核正文并进行二次改写
- 保存章节内容与创作记录
- 自动更新全书大纲和后续章节规划
- 支持版本管理与历史记录
- 提供人物设定、世界观和文风管理
- 提供全书质量检查功能

## 计划中的工作流

1. 作者导入全书大纲。
2. 系统建立小说项目数据库。
3. 作者输入当前章节的核心想法。
4. 系统生成或更新本章细纲。
5. Gemini API 生成第一版正文。
6. DeepSeek API 审核正文。
7. Gemini API 根据审核意见修改正文。
8. 系统检查时间线、人物设定和剧情连续性。
9. 作者审核并确认最终版本。
10. 系统保存章节、更新数据库，并维护全书大纲。

以上是计划中的工作流，具体模型与功能将根据开发进度逐步实现。

## 开发原则

- 优先采用模块化架构。
- 优先保证数据安全与内容可追溯。
- 将模型调用与业务逻辑分离。
- 支持后续增加和替换 AI 模型。
- 关键内容修改应保留版本记录。
- API 密钥不得硬编码进源代码。
- 未经作者确认，不应自动覆盖已确认的正式章节。
- 优先实现稳定、可测试的基础功能，再逐步增加复杂功能。

- 设计数据结构

- 导入全书大纲
- 管理人物设定
- 管理世界观
- 管理章节细纲

### 第三阶段：多模型协作

- 接入正文生成模型
- 接入 DeepSeek 审核模型
- 接入修改与润色模型
- 建立自动化调度流程

### 第四阶段：长篇一致性管理

- 时间线检查
- 人物设定检查
- 剧情连续性检查
- 全书大纲更新
- 章节版本管理

### 第五阶段：完善与开源

- 完善用户界面
- 增加自动化测试
- 完善安装说明
- 编写使用文档
